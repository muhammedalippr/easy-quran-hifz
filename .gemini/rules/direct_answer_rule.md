# Direct Question & Strict Answer Rule

When the user asks a question or includes directives like "only answer":
1. **Provide a direct answer only**: Answer the user's question clearly and concisely.
2. **Do NOT modify code**: Do not perform any file edits, code mutations, or background sync commands unless explicitly asked to modify the code.
3. **Obey Explicit Directives**: Always strictly follow explicit instructions regarding response format and tool usage.
